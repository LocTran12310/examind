# T-03-02 — Thay đổi gần đây

## Context
ADR-02. One row per batch, newest first; a row that cannot be undone says why.

## Implementation notes
A sheet off the bank's toolbar, beside the bar whose work it takes back, on `DataTable` with its own `ch.` URL
prefix so its page and date filter leave the bank underneath untouched. The columns hook is `.tsx` because its
cells are JSX, like the other column hooks. Whether a row can still be taken back is never decided here:
`undoable`, `reason` and `message` come from the server, so an undo simply makes the list say something else —
the original reads "đã được hoàn tác" and the restore appears as its own row.
