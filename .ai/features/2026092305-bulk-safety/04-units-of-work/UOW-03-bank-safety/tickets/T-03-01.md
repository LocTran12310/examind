# T-03-01 — Hoàn tác in the toast

## Context
The mutation answers with the batch id; the toast's action undoes it and refetches.

## Implementation notes
`POST /questions/bulk` still answers `{updated}` only: the handler makes a batch id per request and drops it,
and `BulkOut` has no field for it. The web side reads `batch_id` off that answer and shows "Hoàn tác" when it is
there, so the toast never promises a way back it cannot take; until the field exists, the way in is
"Thay đổi gần đây" (T-03-02), which reads the batches out of the history. One field on `BulkOut` closes it.
